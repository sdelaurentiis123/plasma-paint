What has run

The feature pipeline, constrained painting language, deterministic renderer, and reward checks have run locally. SFT, DPO, and GRPO have entry points and smoke checks; no language-model adapter has been trained yet.

Human aesthetic preferences have not been collected. These measurements do not establish an aesthetic improvement.

Data coverage

These previews use the older 624-frame 85604 archive. The art experiment is restricted to its permitted first 432 frames, with separate art training, validation, test, and guard intervals.

The larger 1,936-frame NERSC run is pending access and split verification. NERSC currently rejects the SSH credential. Shot 85606 data remains unopened.

Metric details and experiment status

Intervals are 95% bootstrap intervals over clips, averaging matched seeds. Fidelity and temporal scores are diagnostic composites, not percentages of physical accuracy. Filament and orientation measures include recorded brush operations; pixel intensity correspondence is a separate check.
